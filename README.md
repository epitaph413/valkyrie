# Valkyrie

A light-lag space combat game set in the War of Shattered Stars. Every ship you see is where she was when her
light left her.

**Play it in your browser: https://epitaph413.github.io/valkyrie/**

- `index.html`: the game's page.
- `play/`: the game itself, solo, as it runs in the browser (three.js, and the ship models in `play/models`).
- `CHANGELOG.md` / `changelog.html`: what changed in each version.
- `THIRD-PARTY-NOTICES.txt`: licences for the software and fonts the game is built with.

Multiplayer needs the Windows app (Valkyrie Host for whoever hosts, Valkyrie for friends), which is shared directly
for now.
